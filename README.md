# 🕌 The Haveli | Restaurant Website

**The Haveli** – where **royal taste meets modern dining**.  
A fully responsive and interactive restaurant website built with **HTML, CSS, and JavaScript**, featuring **online orders, dining reservations, menu display, cart functionality, and feedback forms**.

---

## 🚀 Features

- Homepage with modern fonts, gradients, and high-quality images  
- Menu section with categories, prices, and descriptions  
- Online order system with cart functionality  
- Dining reservation form for booking tables  
- Feedback form for reviews and suggestions  
- Fully responsive design for desktop, tablet, and mobile  

---

## 🛠 Tech Stack

- **HTML5** – Structure of the website  
- **CSS3** – Styling, layout, gradients, animations  
- **JavaScript** – Interactive features like cart, menu filtering, booking  
- **Images** – Stored in `images/` folder

Browse sections: Menu, Online Order, Dining Reservation, Feedback

Add items to cart and place orders

Book tables using the reservation form

Submit feedback to improve the experience
